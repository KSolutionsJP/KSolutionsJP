# Web制作ポートフォリオ

店舗サイト・ランディングページの制作サンプルを公開しています。
すべて自主制作のサンプルです（実在の店舗・企業とは関係ありません）。

## サンプル一覧

### 1. Café こもれび（架空のカフェの店舗サイト）
- デモ：https://ksolutionsjp.github.io/sample-cafe/
- コード：https://github.com/KSolutionsJP/sample-cafe
- 内容：1ページ構成・全10セクション（お知らせ／店主のごあいさつ／メニュー（タブ切り替え）／お客様の声／FAQアコーディオン／予約フォーム（デモ）ほか）
- 技術：HTML / CSS / JavaScript、レスポンシブ対応

### 2. 株式会社タカミネ精工（架空の製造業コーポレートサイト）
- デモ：https://ksolutionsjp.github.io/sample-corporate/
- コード：https://github.com/KSolutionsJP/sample-corporate
- 内容：全5ページ構成（トップ／事業内容／会社概要／お知らせ／お問い合わせ）、共通ヘッダー・フッター、パンくずリスト、お問い合わせフォーム（デモ）
- 技術：HTML / CSS / JavaScript、レスポンシブ対応
